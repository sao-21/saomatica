# SAOmatica — mod Fabric 1.21.1

Commandes : /saomatica help | models | import <fichier> | export <de> <à> <nom> [litematic|schem] | preset | config | undo | folder
Dépose tes .obj/.glb dans le dossier affiché par /saomatica folder.

## Compiler
Java 21 + Gradle 8.10+ :  gradle build   -> build/libs/saomatica-1.0.0.jar
Ou : pousse ce dossier sur GitHub, l'onglet Actions (workflow "build") fournit le jar.
Prérequis : Fabric Loader 0.16.5+ et Fabric API pour 1.21.1.
